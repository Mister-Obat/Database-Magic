# Archives de cartes

Déposez ici les images de cartes que vous possédez déjà, éventuellement dans des
sous-dossiers. L’onglet **Archives** de la Bibliothèque Magic affiche les images
PNG, JPEG, WebP, BMP et TIFF trouvées dans ce dossier.

Avec Tesseract installé, l’OCR local peut lire le nom de la carte et proposer
une impression. Cette reconnaissance est expérimentale. Vérifiez le nom,
l’édition et le numéro de collection avant d’importer l’image dans le catalogue.
Vous pouvez également choisir l’impression manuellement.
