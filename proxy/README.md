# Cartes proxy

Déposez ici les images de vos cartes proxy (PNG, JPEG, WebP, GIF, AVIF ou BMP).
Ouvrez **Perso → Voir les proxies**, puis sélectionnez une image pour l’associer
à une impression réelle. L’image conserve sa place dans l’édition **Proxy**.

Le nom du fichier identifie le proxy. Après un renommage, le fichier apparaît
comme un nouveau proxy.
